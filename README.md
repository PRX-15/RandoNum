# 🎲 Random Number Generator

A simple, clean random number generator built with **HTML, CSS, and JavaScript**.

Enter a minimum and maximum number, click **Generate**, and the website will generate a random whole number within that range.

## ✨ Features

- 🎲 Generates random numbers
- 🔢 Custom minimum and maximum values
- ⚡ Instant results
- 📱 Responsive design
- 🧩 No frameworks or dependencies
- 🌐 Can be hosted directly with GitHub Pages

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
